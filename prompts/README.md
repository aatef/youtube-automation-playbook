# Prompt Library

[← Back to README](../README.md)

Copy-paste prompts for each stage of the pipeline. They work with any capable LLM (Claude, ChatGPT, Gemini).

**How to use:** replace every `{placeholder}` before you run a prompt. Prompts give you a **first draft**: a human must edit, fact-check and approve everything before it's published. See [AI Usage](../docs/ai-usage.md).

| File | Stage |
|---|---|
| [niche-research.md](niche-research.md) | Niche selection, competitor and outlier analysis, idea generation |
| [scripting.md](scripting.md) | Outlines, hooks, full scripts, script review |
| [titles-thumbnails.md](titles-thumbnails.md) | Titles, thumbnail concepts, descriptions, tags |
| [video-generation.md](video-generation.md) | Shot lists and prompts for AI video and image generators |
