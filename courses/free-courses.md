## How to add a course
Copy a row and update it:
```
| 7 | Course name | Instructor | Playlist | https://www.youtube.com/playlist?list=PLAYLIST_ID | ☐ Not started | |
```
For a single-video course, set **Type** to `Video` and use a `watch?v=` link.
