## 🧠 Skills to build (in order)
> Prompts for every stage are in the [Prompt Library](../prompts/README.md).

1. **Niche and topic research.** Outlier analysis, search demand, RPM by niche.
2. **Scriptwriting.** Hooks, story structure, pattern interrupts.
3. **Packaging.** Titles and thumbnails, designed together before production.
4. **Production pipeline.** Voice (human or licensed AI), editing, B-roll sourcing and copyright safety.
5. **Team and SOPs.** Hiring writers, editors and thumbnail designers; quality-control checklists.
6. **Analytics loop.** Weekly review of retention, CTR and topic performance.
7. **Automation tooling.** LLMs for research and drafts, workflow tools (n8n/Make), the YouTube Data API for reporting.
